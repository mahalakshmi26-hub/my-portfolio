What is a 404 Error and How to Fix Broken Links on Your Site

M
Mahalakshmi Marimuthu
·5 min read·August 2026

Everyone's hit a "Page Not Found" screen at some point — but if visitors are hitting them on your site, it's costing you more than you might think. Here's what a 404 error actually is and how to clean them up.

What is a 404 Error?

A 404 error is the response a server sends when someone requests a page that doesn't exist at that URL. It's one of many HTTP status codes — 404 specifically means "not found."

It happens for a few common reasons: a page was deleted, a URL was changed without a redirect, someone typed the address wrong, or an old link — internal or external — points somewhere that no longer exists.

Why 404s Matter for SEO

  • Broken user experience. A visitor who lands on a dead end is more likely to leave your site entirely — especially if they arrived from a search result or a link elsewhere.
  • Wasted crawl budget. Search engines spend time crawling dead pages instead of your live, valuable content — a bigger issue on large sites.
  • Lost link equity. If another website links to a page on your site that now 404s, all the SEO value that link could have passed is going nowhere.
Important nuance: a small number of 404s is completely normal and not something to panic over — pages naturally get removed over time. The real problem is unaddressed 404s that still receive traffic or links.

Types of 404s Worth Knowing

TypeWhat It Means
Hard 404Server correctly returns a 404 status code — this is the proper way to signal a missing page
Soft 404Page displays "not found" content but the server returns a 200 (success) status — confuses search engines

Soft 404s are the sneakier problem — Google Search Console specifically flags these because they can lead to broken pages being indexed as if they were valid.

How to Find Broken Links on Your Site

  1. Google Search Console: check the Pages report under Indexing for "Not Found (404)" errors Google has already discovered.
  2. Site crawler tools: free tools like Screaming Frog (free up to 500 URLs) can crawl your entire site and list every broken internal link.
  3. Check your analytics: look for high-traffic 404 pages — these deserve priority since real visitors are hitting them.

How to Fix Them

1. Redirect it, if the content moved

Use a 301 redirect to send visitors (and search engines) from the old URL to the new, correct one. This preserves most of the page's SEO value.

2. Fix the internal link, if that's the cause

If a broken link is coming from your own site's navigation, content, or footer, simply update the link to point to the correct URL — no redirect needed.

3. Recreate the content, if it still matters

If a valuable page was deleted by mistake or during a migration, and there's no clear replacement, consider republishing it or a close equivalent.

4. Leave it as a real 404, if the page is genuinely gone

Not every dead page needs a redirect. If content is truly obsolete and irrelevant, a clean 404 (rather than redirecting it to an unrelated page) is actually the more honest, search-engine-friendly choice.

Avoid this shortcut: redirecting every dead URL to your homepage "just in case" is a common mistake. Search engines can flag this as a soft 404 pattern, and it gives visitors a confusing experience instead of what they were actually looking for.
The takeaway: 404s aren't inherently bad — they're a normal part of how the web works. The goal isn't zero 404s, it's making sure the ones that matter (high-traffic, well-linked pages) get properly redirected or fixed.
