What This Tool Does

The Internet Archive's Wayback Machine has saved copies of billions of web pages since 1996. Its calendar is great for browsing, but it doesn't tell you what the history means. Enter any domain or page URL and this tool pulls every archived day, then shows when the page was live, when it redirected (and where), when it broke, and any long gaps — with plain-English red flags you can act on.

Key Features

📊
History at a Glance
First seen, last seen, archived days, years active, content versions and longest gap — plus a snapshots-per-year chart split by status.
🚩
Red Flags for Due Diligence
Flags long archive gaps (possible expiry), redirects to another domain, error periods, and thin or stale history before you buy or migrate a domain.
🧭
Status & Redirect History
A colour timeline of when the page returned 200, 301 or 404 — and the archived redirect target for each redirect period.
↔️
Before / After Picker
Pick a date, like a traffic drop, and get the snapshot just before and just after it, with a one-click Wayback compare link.
🗂
Old Pages Finder
Optionally list up to 1,000 old HTML pages the archive has seen on a domain — handy for recovering lost content and redirects.
📥
Archive Now + CSV Export
Save the current version of a page to the Wayback Machine in one click, and download snapshots or pages as CSV.

How to Use It

1
Enter a domain or page URL
Use a homepage to check a whole domain's story, or a specific page to trace its own history. Add a year range if you only care about one period.
2
Read the red flags and status history
See gaps, redirects and error periods at a glance, then open any snapshot to check what the page looked like.
3
Compare, export, archive
Compare before/after a key date, download the CSV, and archive the live page so its history stays complete.

Why I Recommend It

When rankings drop, the first question is always “what changed?” — and the Wayback Machine is often the only record. I built this to answer that question fast, and to vet domains before a purchase or migration, without clicking through years of calendar pages.

  • Turns raw archive data into clear findings, not just a list of dates
  • Shows where old redirects pointed — useful for migrations and expired-domain checks
  • Uses the Internet Archive's free official API — no sign-up, no API key

Note: the Wayback Machine doesn't archive every page or every day, and some sites ask to be excluded. Gaps can mean the site was offline — or simply that nobody archived it then.
