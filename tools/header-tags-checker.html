What This Tool Does

Paste one or more URLs and the tool fetches each page, extracts every H1–H6 heading in the exact order it appears, and displays it as an indented outline so you can see the page's structure the way search engines do. It then runs three checks on every page — missing H1, multiple H1s, and skipped heading levels (like jumping from H2 straight to H4) — and gives you a clean summary table you can export.

Why I Built It

Heading structure is one of the first things I check in any on-page audit — and one of the most tedious to check manually. Opening dev tools on every page, scanning for the H1, counting duplicates, tracing whether the levels flow logically… it doesn't scale past a handful of URLs. So I built this to do it in bulk, the way I actually work.

  • Before content revamps, I run the whole section through it to find pages with missing or duplicate H1s — a surprisingly common issue on template-driven pages.
  • Skipped heading levels (H2 → H4) often reveal that designers styled headings for looks, not structure — this tool surfaces those instantly with the exact transition.
  • The indented tree doubles as a quick content outline review: if the heading structure doesn't tell the page's story on its own, the content usually needs work too.
