What This Tool Does

A single wrong line in robots.txt can block a whole site from Google, so I wanted a generator that doesn't just output a file — it explains what the file will do. You set the rules with dropdowns and checkboxes, watch the file update live, and get plain-English warnings before anything goes live.

Key Features

🎛️
Per-Crawler Rules
Allow or refuse Google, Bing, Yandex, Baidu and more individually, on top of a default allow/refuse setting and crawl-delay.
🧠
AI Crawler Control
One click to block GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot and other AI crawlers — or explicitly allow them.
⚡
Platform Presets
Starter rules for WordPress, Shopify, Magento and generic e-commerce sites, plus allow-all and block-all (staging).
✅
Checks & URL Tester
Warnings for risky rules (like blocking Googlebot or CSS/JS) and a tester that shows whether any URL is allowed or blocked for a chosen bot.

How to Use It

1
Pick a preset
Start from allow-all, block AI crawlers, WordPress, Shopify and so on — then adjust anything you like.
2
Tune the rules
Add your sitemap, crawl-delay, blocked paths and per-crawler rules. The robots.txt preview updates as you type.
3
Test, copy and upload
Test a few URLs, copy or download the file, and upload it to the root of your site at /robots.txt.

Why I Built It

Robots.txt is one of the quickest technical SEO wins and one of the easiest ways to accidentally hurt a site. I built this so I can create a safe file quickly, sanity-check it against real URLs, and show clients exactly what each rule does.

  • Runs entirely in the browser — nothing you type is sent to a server
  • Repeats path rules inside per-bot groups so an allowed bot doesn't accidentally bypass your blocks
  • Uses Google's longest-match logic in the URL tester
