Meta Details Extractor

Extract H1, meta title, meta description & meta keywords from up to 200 URLs in one go — built for SEOs who audit at scale.

Free On-Page SEO Bulk Audit Python + Streamlit

What This Tool Does

Checking meta tags one URL at a time is slow. This tool fetches up to 200 URLs in parallel and returns each page’s H1, meta title, meta description and meta keywords in a single table — with character counts and “missing” flags so on-page gaps jump out instantly. Ideal for content audits, migration QA and competitor teardowns.

Key Features

⚡
Bulk Extraction
Paste up to 200 URLs — fetched in parallel, results in seconds, in your original order.
📏
Character Counts
Title and description lengths included, so truncation risks are visible at a glance.
🚩
Missing-Tag Flags
Pages without an H1, title or description are flagged ❌ and counted in the summary.
📥
CSV & Excel Export
Download the full results table for your audit deck or client report in one click.

How to Use It

1
Paste Your URLs
One URL per line — https:// is added automatically if you skip it. Duplicates are removed.
2
Hit Extract
The tool fetches all pages in parallel and shows a live progress bar.
3
Review & Download
Scan the summary metrics and results table, then export as CSV or Excel.

Why I Built It

As an SEO working across hundreds of product pages, I needed a fast way to spot meta-tag gaps without firing up a full crawler. I built this with Python and Streamlit so it stays free, fast and simple. I use it for:

  • Pre- and post-migration QA — confirming titles and descriptions survived a site change
  • Quick on-page audits before deeper crawls — finding missing H1s and descriptions in minutes
  • Competitor snapshots — pulling meta patterns across rival landing pages for positioning ideas
